# 🧠 Holberton School — Algorithm Interview Prep

> A collection of algorithm and data structure projects built at Holberton School, covering classic interview problems in Python and JavaScript.

---

## 📖 About

This repository contains solutions to algorithmic challenges tackled during the Holberton School curriculum. Each project is self-contained with its own documentation, and covers a range of problem-solving techniques: graph traversal, backtracking, bitwise operations, greedy algorithms, and API consumption.

---

## 📁 Projects

| Project | Language | Topic | Description |
|---------|----------|-------|-------------|
| [lockboxes](./lockboxes/) | Python | Graph traversal | Determine if all locked boxes can be opened |
| [minimum_operations](./minimum_operations/) | Python | Prime factorization | Fewest Copy/Paste operations to reach n characters |
| [nqueens](./nqueens/) | Python | Backtracking | Place N non-attacking queens on an N×N chessboard |
| [pascal_triangle](./pascal_triangle/) | Python | Iterative algorithm | Generate Pascal's Triangle up to n rows |
| [starwars_api](./starwars_api/) | JavaScript | REST API / async | Print Star Wars movie characters in order via SWAPI |
| [utf8_validation](./utf8_validation/) | Python | Bitwise operations | Validate a dataset as valid UTF-8 encoding |
| [log_parsing](./log_parsing/) | Python | Stdin / metrics | Parse HTTP logs and compute running statistics |
